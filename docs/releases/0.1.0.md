# tgskk 0.1.0

Linux向けSKKの初回リリースです。
CSKKによる変換と、ローカルAIによる文脈に応じた候補順位の調整を組み合わせています。

- fcitx5・IBusに対応。
- 読みの入力中に非同期で採点し、変換時に間に合った結果だけを使用。候補表示後は順序を変えません。
- 最初の4候補はインライン、5候補目から一覧表示。
- ローカル辞書に候補がない場合は、同梱のGoogle IME SKK serverで補完。独自serverとEUC-JP／UTF-8通信も設定できます。

## 導入

x86_64のArch Linux、Debian 13、Ubuntu 24.04／26.04 LTS向けアーカイブを添付しています。
使用するOSのアーカイブを展開し、共通パッケージと使用するフロントエンドを一緒にインストールしてください。
詳細は[導入手順](https://github.com/yoshitsugu/tgskk/blob/v0.1.0/docs/distribution.md)を参照してください。

モデルの重みは同梱していません。
文脈補助を使う場合は、AVX2対応CPUで、導入後に一般ユーザーとして`tgskk-setup-model`を実行します（約74MB取得）。
モデルが利用できない場合も辞書で入力できます。

## 通信と制約

AI推論はローカルで完結します。
Googleによる補完は既定で有効で、ローカル候補がない読みを外部へ送信します。
周辺文脈は送信しません。
外部送信を無効にする場合は`SkkservMode=Disabled`に設定してください。

文脈補正はCPUと入力速度・負荷によって間に合わない場合があり、その場合は辞書・学習の順序を使います。
macOS・Windows・ARM CPUは今回の配布対象外です。
候補窓やモード表示の見た目は入力フレームワークとデスクトップに依存します。
