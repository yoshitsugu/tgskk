# tgskk 0.2.0

## 主な変更

- fcitx5とIBusに設定画面を追加しました。辞書、AIによる文脈補助、SKKサーバなどを設定できます。
- ローカルAIによる候補の順位調整で、カーソルの前後の文章を利用するようにしました。
- IBusの入力モードを色で見分けられるようにしました。

## Linuxの導入

x86_64のArch Linux、Debian 13、Ubuntu 24.04／26.04 LTS向けのアーカイブを配布します。
使うOSのアーカイブを取得し、`SHA256SUMS`で照合したうえで、共通パッケージとfcitx5またはIBusのパッケージを一緒にインストールしてください。
ローカルAIを使う場合は導入後に一般ユーザーとして`tgskk-setup-model`を実行してください。モデルの重みはLinuxパッケージに含まれません。[導入手順](https://github.com/yoshitsugu/tgskk/blob/v0.2.0/docs/distribution.md)

Googleによる候補の補完は既定で有効です。
ローカル辞書に候補がないとき、変換対象の読みをGoogleに送ります。
外部送信を無効にするには、設定画面でSKKサーバを無効にするか、設定ファイルで`SkkservMode=Disabled`を指定してください。[利用ガイド](https://github.com/yoshitsugu/tgskk/blob/v0.2.0/docs/usage.md)

## Windows x64プレビュー

Windows版は同じバージョンのプレビューとして別のリリースに掲載します。
セットアップには辞書、AIモデル、設定画面が含まれ、インストール時にGoogleへの読みの送信を無効にできます。
セットアップは未署名です。Windowsが実行時に警告を出したり、実行をブロックしたりする場合があります。
アプリごとの互換性は検証中です。[Windowsの導入手順](https://github.com/yoshitsugu/tgskk/blob/v0.2.0/addons/windows/README.md) · [リリース一覧](https://github.com/yoshitsugu/tgskk/releases)
