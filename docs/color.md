# カラーパレット

野営道具のような、落ち着いたオリーブを基本色にする。
カーキとブラウンをアクセントに使い、白や黒も少し暖かみのある色に揃える。

| 名前 | カラーコード | 用途 |
| --- | --- | --- |
| `olive` | `#4F5838` | 基本色。モード変更ポップアップなどの背景 |
| `olive-deep` | `#333C29` | 濃いオリーブ。影や引き締める部分 |
| `khaki` | `#B8A779` | カーキ。枠線、選択状態、小さな装飾 |
| `brown` | `#79543A` | ブラウン。補助的な強調色 |
| `slate` | `#465E73` | 青みのある灰色。半角カタカナのモード表示の背景 |
| `canvas` | `#F3F0E4` | 生成り。濃い背景上の文字、明るい面の背景 |
| `ink` | `#292D23` | 墨色。明るい背景上の文字 |

## 組み合わせ

| 場面 | 背景 | 文字 | 枠線 |
| --- | --- | --- | --- |
| モード変更ポップアップ(ひらがな) | `olive` | `canvas` | `khaki` |
| モード変更ポップアップ(カタカナ「ア」) | `olive-deep` | `canvas` | `khaki` |
| モード変更ポップアップ(半角英数「A」) | `khaki` | `ink` | `olive` |
| モード変更ポップアップ(全角英数「Ａ」) | `brown` | `canvas` | `olive-deep` |
| モード変更ポップアップ(半角カタカナ「ｱ」) | `slate` | `canvas` | `khaki` |
| 選択状態 | `khaki` | `ink` | `olive` |
| 補助的な強調表示 | `brown` | `canvas` | `olive-deep` |

オリーブ背景の文字には`canvas`を使い、`khaki`は半角英数のモード表示を除いて枠線や装飾に留める。
モードの違いは「あ」「ア」「A」などの文字で示し、ひらがな以外のモードは背景色でも区別する。
カタカナはひらがなと同じ日本語入力なので同系色の`olive-deep`にし、半角英数は日本語入力でないことがすぐわかるよう明るい`khaki`にする。
全角英数は英字入力でありながら半角英数とは別物であることを示すため、`brown`にする。
半角カタカナは、既存の色だけでは明るさも色相も他のモードと重なるため、青みのある`slate`を足して区別する。
`slate`は明るさを`olive`と揃えつつ青黄方向にずらし、P型・D型の色覚でも他の背景色と見分けられるようにしている。
OSの高コントラスト設定が有効な場合は、システム色を優先する。
